<strong>Our MaxCut Problem Statement</strong>: Given an undirected weighted random graph, divide the nodes into two sets such that the sum of the weights is maximised.

<strong>Mathematically</strong>: Consider an undirected graph $G=(V,E)$ with edge weights $w_{uv}$ associated with each edge $(u,v)\in E$. Find $\mathbf{s}\in(\pm1)^{\lvert V\rvert}$ giving us:

$$\max_{\mathbf{s}} C(\mathbf{s}):=\max_{\mathbf{s}}\sum_{(u,v)\in E}\frac{w_{uv}}{2}(1-s_us_v)\equiv-\min_{\mathbf{s}}\sum_{(u,v)\in E}s_us_vw_{uv}.$$

The cost function $C(\mathbf{s})$ has been found by case analysis. Upon the cut, the graph will be separated in two groups of nodes $\mathcal{A}$ and $\mathcal{B}$. We would like to sum the contributions of nodes $(u,v)$ that do not belong to the same group, otherwise it means that the corresponding edge has not been cut. Now, assign the value $s=1$ for nodes in group $\mathcal{A}$ and $s=-1$ for nodes in group $\mathcal{B}$. Thus for two nodes in the same group, it must be that $s_us_v=1$, while for two nodes in different groups, $s_us_v=-1$. In other words, we need to account for all the cases where $s_u\neq s_v$. To have positive contributions we must consider $-s_us_v$,
and we need the value zero whenever $s_u=s_v$ which can be enforced by setting $1-s_us_v$. Finally, by symmetry $w_{uv}=w_{vu}$, leading to a double count of the weights hence the necessity to divide by 2 in the cost function.  

Now, recall that the Pauli-$Z$ operator is diagonal with eigenvalues $\pm 1$. Hence, $Z_uZ_v\ket{s}=(-1)^{s_u+s_v}\ket{s}$. As a result, we can encode the cost function on qubits, giving us a <strong> cost Hamiltonian</strong> $H_C$ of the form:

$$H_C=\sum_{(u,v)\in E}w_{uv}Z_uZ_v.$$

By construction, we have that $H_C\ket{\mathbf{s}}=C(\mathbf{s})\ket{\mathbf{s}}$ (up to an additive constant independent of $\mathbf{s}$), and so maximising the cut value is equivalent to minimising the expectation $\bra{\mathbf{s}}H_C\ket{\mathbf{s}}$ of $H_C$. This task is the solution of a variational quantum algorithm, where we will choose a parametrised trial state $\ket{\psi(\vec{\theta})}=U(\vec{\theta})\ket{\psi_{\textup{initial}}}$ for a parametrised unitary $U(\vec{\theta})=U_N(\theta_N)... U_1(\theta_1)$, with $\vec{\theta}=(\theta_1,...,\theta_N)^\top$ and initial state $\ket{\psi_{\textup{initial}}}$. For this setup, with $(\ket{\psi_0},E_0)$ the ground state / energy of $H_C$, the variational principle tells us that: 

$$E_0=\bra{\psi_0} H_C\ket{\psi_0}\leq\bra{\psi(\vec{\theta})} H_C\ket{\psi(\vec{\theta})}$$ 

for which we hope to approach the true ground state energy $E_0$ with the parametrised state:

$$\min_{\vec{\theta}}\bra{\psi(\vec{\theta})} H_C\ket{\psi(\vec{\theta})}\gtrsim E_0.$$

Let us now construct the unitary $U(\vec{\theta})$. An important ingredient in Hamiltonian simulation is the Suzuki-Trotter decomposition of the time-evolution operator generated by a Hamiltonian. 
However, at the moment we have a problem ! We will initialise the QAOA circuit with an equal superposition of the $2^{|V|}$ basis states. Applying a time-evolution operator of $H_C$ on such a state $\ket{\Phi}$ yields:

$$e^{-i\gamma H_C}\ket{\Phi}=\frac{1}{\sqrt{2^{|V|}}}\sum_{\mathbf{s}\in(\pm 1)^{|V|}}e^{-i\gamma H_C}\ket{\mathbf{s}}=\frac{1}{\sqrt{2^{|V|}}}\sum_{\mathbf{s}\in(\pm 1)^{|V|}}e^{-i\gamma C(\mathbf{s})}\ket{\mathbf{s}}.$$

Now remark that the probabilities of measuring the state $\mathbf{s}$ are given by:

$$\mathbb{P}(\mathbf{s})=\left|\bra{\mathbf{s}}e^{-i\gamma H_C}\ket{\Phi}\right|^2=\left|\frac{e^{-i\gamma C(\mathbf{s})}}{\sqrt{2^{|V|}}}\right|^2=\frac{1}{2^{|V|}},$$

which are the same probabilities of measuring state $\mathbf{s}$ in the original state $\ket{\Phi}$. Thus, the cost Hamiltonian alone would <strong> not </strong> help us find better solutions. 
To have a practical Hamiltonian, we must introduce a so-called <strong>mixer Hamiltonian</strong> $H_M$. For such a map, we should not observe that all the states $\mathbf{s}$ are eigenstates of the mixer, and moreover it must have the faculty to be able to connect the feasible solution space. We will choose:

$$H_M=\sum_{u\in V}X_u,$$

where $X$ is the Pauli-$X$ operator. 

Finally, on a time-interval $[0,T]$, we set the time-dependent Hamiltonian 

$$H(t)=(1-t/T)H_M+(t/T)H_C,\hspace{0.5cm}\textup{$H(0)=H_M$ and $H(T)=H_C$}$$

for which the Trotter decomposition of its time-evolution operator is 

$$e^{-iH\Delta t}\approx e^{-i\gamma H_C}e^{-i\beta H_M},\hspace{0.5cm}\textup{ $\beta=(1-t/T)\Delta t$ and $\gamma=(t/T)\Delta t$.}$$

By optimizing the parameters $\gamma$ and $\beta$, we aim to make states $\mathbf{s}$ with larger cut values more likely to appear. As a straightforward generalisation, we can consider a non-uniform time function $g(t)$, at a depth $p$, for some angles $\gamma_i$ and $\beta_i$, $i=(1,..., p)$. So, for a set of parameters $\vec{\theta}=(\vec{\gamma},\vec{\beta})=(\gamma_1,...,\gamma_p,\beta_1,...,\beta_p)$, the $p$-layers QAOA parametrised quantum circuit is given by: 

$$U(\vec{\gamma},\vec{\beta})=\prod_{j=1}^pe^{-i\gamma_j H_C}e^{-i\beta_j H_M}.$$

See the project presentation slides and the GitHub repository for a Qiskit implementation of the QAOA circuit on a weighted random graph with $\lvert V\rvert=7$, $p=2$ and 4 parameters to estimate. This project also includes a study of the robustness of the model against noise, where we compare the QAOA cost against the noise parameter for different number $p$ of layers. This comparison has been made for a depolarising noise, a bit-flip and a dephasing noise.
